Python & Agentic AI Engineer
Northline Labs — Remote / Hybrid

About the role
We are hiring a Python and Agentic AI Engineer to build backend services, data pipelines, and
tool-using AI agents. You will connect language models to real company data with FastAPI,
PostgreSQL, and Model Context Protocol (MCP) servers. This is a hands-on role for someone who
can ship secure APIs and grounded multi-agent workflows.

Responsibilities
- Design and build FastAPI and Flask services with AsyncIO
- Create REST APIs with authentication using OAuth and JWT
- Model data in PostgreSQL, SQL Server, or SQLite with SQLAlchemy
- Build ETL pipelines that move documents into vector stores such as ChromaDB
- Develop MCP servers and tool-calling workflows for AI agents
- Build RAG and multi-agent systems with LangChain and LangGraph
- Use Docker and GitHub Actions for reliable deploys
- Collaborate with the team through Git, code review, and clear documentation

Requirements
- 3+ years of professional software or freelance product experience
- Strong Python skills
- Production experience with FastAPI and REST APIs
- Hands-on work with PostgreSQL or similar SQL databases
- Experience with RAG, LangChain, or agentic AI systems
- Familiarity with Docker and Git
- Bachelor's or Master's degree in Computer Science, or equivalent practical experience

Nice to have
- MCP server development
- Amazon S3, ChromaDB, or other data/vector storage
- PyTorch, Hugging Face, or NLP evaluation (BLEU, ROUGE)
- React, Next.js, or Tailwind CSS for internal tools
- Power BI dashboards
- Streamlit prototypes

We value honest resumes. Please only list skills and projects you can discuss in an interview.
